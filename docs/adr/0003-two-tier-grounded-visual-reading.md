# Two-Tier Grounded Visual Reading Pipeline

Every **Visual Reading** follows a two-tier grounding architecture: Stage 1 produces a lossless **Grounded Page Breakdown** (`## [Page N]`) using `Qwen2.5-VL`'s native structural representations (HTML `<table>` with `rowspan`/`colspan`, LaTeX equations, linearized chart data tables, and verbatim anchor quotes) with `=== PAGE N ===` image markers and a 1-page read-only visual context prefix across window boundaries; Stage 2 synthesizes those page transcripts into a NotebookLM-style, `[Page N]`-cited **Executive Synthesis** presented above the full Page-by-Page Grounded Breakdown. Asking a 7B vision model to directly summarize multi-page images in a single leap drops dense numerical cells and misattributes page citations, whereas grounding synthesis in an explicit per-page structural transcript achieves high-fidelity extraction and verifiable page citations.
