# Adaptive Single-Pass and Map-Reduce Page Windowing

We process PDFs in bounded 3-page **Page Windows** (`~7k–9k` visual tokens per window at `200` DPI and `1792px` max side) with a default concurrency of `1`, returning a single-pass reading for documents up to 3 pages and a two-stage Map-Reduce reading (per-window structural extraction followed by a document-level synthesis pass on `Q-Vision`) for longer documents. Sending an entire multi-decade page PDF or overly dense 6-image windows in a single multimodal request compresses per-page visual attention on embedded diagrams and risks tripping oMLX unified-memory prefill guards on Apple Silicon, whereas 3-page windows preserve embedded scene-text callouts and chart gridline precision while still producing a unified document-level reading.
